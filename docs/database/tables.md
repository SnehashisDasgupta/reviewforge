# ReviewForge - Database Tables

## Purpose

This document defines the database tables required for Version 1 of ReviewForge.

Each table is mapped directly from the domain model and represents a persistent business entity. Detailed column definitions will be documented individually before implementation.

---

# Database Overview

| Table | Purpose |
|--------|---------|
| users | Stores registered users |
| repositories | Stores software repositories |
| repository_members | Stores repository memberships and roles |
| repository_invitations | Stores collaboration invitations |
| directories | Represents folder hierarchy |
| code_files | Stores uploaded project files |
| file_versions | Stores historical versions of files |
| reviews | Stores AI review requests |
| review_results | Stores AI review summaries |
| review_issues | Stores individual issues detected during reviews |
| documentations | Stores generated documentation |
| documentation_versions | Stores documentation history |
| notifications | Stores user notifications |

---

# Table Details

## users

### Purpose

Stores registered developers and their account information.

### Responsibilities

- Authentication
- Profile information
- Repository ownership
- Collaboration identity

---

## repositories

### Purpose

Represents software projects managed within ReviewForge.

### Responsibilities

- Repository metadata
- Ownership
- Visibility
- Configuration

---

## repository_members

### Purpose

Represents user membership within a repository.

### Responsibilities

- Repository roles
- Permission checks
- Membership history

---

## repository_invitations

### Purpose

Stores pending collaboration invitations.

### Responsibilities

- Invitation status
- Expiration
- Acceptance tracking

---

## directories

### Purpose

Represents the folder structure of uploaded projects.

### Responsibilities

- Parent-child hierarchy
- Folder organization

---

## code_files

### Purpose

Stores uploaded source code and resource files.

### Responsibilities

- File metadata
- Repository association
- Directory association

---

## file_versions

### Purpose

Stores historical versions of uploaded files.

### Responsibilities

- Version history
- Upload tracking
- Future diff support

---

## reviews

### Purpose

Stores AI review requests.

### Responsibilities

- Review lifecycle
- Processing status
- Review ownership

---

## review_results

### Purpose

Stores the overall outcome of an AI review.

### Responsibilities

- Summary
- Quality score
- AI recommendations

---

## review_issues

### Purpose

Stores individual issues identified during an AI review.

### Responsibilities

- Severity
- Description
- Suggested improvements
- File references

---

## documentations

### Purpose

Stores generated documentation metadata.

### Responsibilities

- Documentation type
- Repository association
- Current version

---

## documentation_versions

### Purpose

Maintains historical documentation versions.

### Responsibilities

- Version history
- Export support
- Generation tracking

---

## notifications

### Purpose

Stores user notifications generated by system events.

### Responsibilities

- Notification content
- Delivery status
- Read status

---

# Version 1 Scope

The following tables are intentionally excluded from Version 1:

- organizations
- organization_members
- github_integrations
- api_keys
- audit_logs
- ai_models
- vector_embeddings
- repository_chats
- chat_messages
- billing_accounts

These will be introduced in future phases as the platform evolves.
